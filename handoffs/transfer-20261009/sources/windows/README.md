# Windows Transfer source snapshot

This packet preserves exact handwritten source bytes and a closed local import
graph for the named semantic construction and inverse modules. Use Lean 4.30.0
and mathlib c5ea00351c28e24afc9f0f84379aa41082b1188f. The receiver must independently
prepare its dependency cache and replay narrow modules with LEAN_NUM_THREADS=1,
finite memory/time bounds and exactly one heavy verifier. No caches or binaries
are supplied or committed.

Only the named portable receipt summaries describe actual kernel observations.
The eight inverse/canonical modules are unrun drafts in this snapshot. Hashes
establish byte identity; they do not establish semantic correspondence. This is
a sharing snapshot, not an atomic evidence refresh or complete Transfer result.

Windows owns its source and receipt directory. Mac owns its own source and
receipt directory. Serialize pushes on codex/security-assurance, fetch and rebase
before a push, never force push, and do not merge to main as part of this handoff.
